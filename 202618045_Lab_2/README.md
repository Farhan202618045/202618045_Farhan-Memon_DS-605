## Project Details
This assignment is divided into two parts:
- **Part A:** Vectorized programming using NumPy — array creation, statistics, 
  indexing, linear algebra operations, and normal distribution sampling.
- **Part B:** Data wrangling and exploratory analysis on the Titanic dataset using 
  Pandas — filtering, aggregation, handling missing values, feature engineering, 
  and visualization.

  ## Key Observations
- Female passengers had a significantly higher survival rate (~74%) than male 
  passengers (~19%).
- Survival rate decreased steadily from 1st to 3rd class, and Fare/Pclass were 
  the strongest numerical predictors of survival.
- Age and Cabin had substantial missing data (~20% and ~77% respectively); 
  Age was imputed using multiple strategies (mean, median, mode, random).
- Fare contained a notable number of outliers, mostly high-paying 1st class passengers.
- Passengers traveling with a small family had somewhat better survival odds than 
  those traveling completely alone.
